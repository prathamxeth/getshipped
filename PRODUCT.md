# GetShipped Product Architecture & Strategy

## 1. Product Mission
GetShipped is an autonomous developer RAG agent and omnichannel launch platform. It bridges the gap between raw git commits and developer marketing: transforming complex AST code diffs into viral 60fps Remotion motion graphics videos, word-level kinetic captions, high-engagement X threads, LinkedIn thought-leadership posts, Hashnode technical deep-dives with live Mermaid architecture diagrams, and GitHub README diffs.

## 2. Target Users & Developer Personas
- **Developer A (Core User):** Staff / Principal Systems Engineer, Open Source Creator, or AI Researcher who ships complex code and needs high-fidelity technical launch assets without manual video editing or marketing copywriting.
- **Audience:** Highly technical developers, system architects, engineering leaders, and open-source contributors who respond to latency benchmarks, AST code diffs, architecture DAGs, and real engineering trade-offs rather than generic marketing fluff.

## 3. Core Workflow Primitives (Single-Tab Flow)
1. **Interactive Developer Onboarding:** Profile setup, voice calibration (Systems / Viral / Founder), connected repositories, and commit ingestion.
2. **Interactive RAG Intelligence Console:** Real-time query routing, AST knowledge graph traversal, latency benchmarking (14.2ms TTFT), and lock-free ring-buffer inspection.
3. **Remotion v4 60fps Video Studio:** Live in-browser 60fps playback, 16:9 and 9:16 aspect ratio switching, macOS code diff morphing, 3D cursor zoom gimbal, and kinetic captions overlay.
4. **Omnichannel Approval & Editor Suite:** Review and refine X threads, LinkedIn posts, Hashnode markdown (with live Mermaid SVG flowcharts), and README pull requests.
5. **In-App 1-Click Export & Restate Dispatch:** In-browser MP4 video rendering and durable Restate saga orchestration dispatching to all social channels with rollback safety.
